# Budget Tracker

**내 돈이 어디로 가는지, 이제 정확하게 파악하세요.**

단순히 기록하는 가계부가 아닙니다. 스마트한 자동화와 명확한 분석으로 재정 흐름을 진짜로 이해할 수 있는 앱입니다.

🌐 **[앱 바로가기](https://budget-tracker-f3nf.vercel.app)** · 🇺🇸 **[English README](README.md)**

---

## 주요 기능

### 거래 내역 관리
수입과 지출을 빠르게 기록하세요. 날짜, 카테고리, 결제 수단, 키워드로 검색하고 필터링할 수 있습니다. 원하는 방식으로 정렬하고 찾아볼 수 있습니다.

### AI 영수증 자동 인식
영수증에 카메라를 갖다 대면 끝입니다. AI가 상점명, 날짜, 총금액, 품목까지 자동으로 읽어줍니다. 직접 입력할 필요가 없습니다.

### 스마트 자동 카테고리 분류
앱이 내 소비 패턴을 학습합니다. 규칙 기반 → 패턴 학습 → AI 순서로 거래를 자동 분류해 손을 거의 쓸 일이 없습니다.

### 월별 · 연간 리포트
돈이 실제로 어디에 쓰였는지 한눈에 파악하세요. 카테고리별 지출 비중, 수입·지출 비교, 시간에 따른 변화를 명확한 차트로 확인할 수 있습니다. 연간 전체 리포트도 제공합니다.

### 예산 목표 설정
카테고리별 월 지출 한도를 설정하세요. 시각적인 프로그레스 바로 한도 대비 현재 지출을 확인하고, 한도에 가까워지면 알림을 받습니다.

### 자동 반복 지출
구독 서비스나 고정 지출은 한 번만 설정하면 됩니다. 매달 지정한 날짜에 자동으로 거래가 기록됩니다. 월세, 스트리밍, 통신비 모두 자동 처리됩니다.

### 캘린더 뷰
달력에서 날짜별 지출을 한눈에 확인하세요. 날짜를 탭하면 그날의 상세 내역을 볼 수 있습니다. 소비 패턴을 직관적으로 파악하기에 좋습니다.

### CSV 가져오기
스프레드시트로 가계부를 관리하고 있었나요? CSV 파일로 기존 데이터를 한번에 가져올 수 있습니다. 카테고리를 자동으로 매핑하고, 가져오기 전에 미리 검토할 수 있습니다.

### 푸시 알림
매일 지출 기록 리마인더를 받으세요. 예산 한도에 가까워지면 알림으로 알려줍니다. 챙기지 않아도 가계부가 알아서 챙겨줍니다.

### 멀티 기기 동기화
데이터는 클라우드에 저장됩니다. 폰, 태블릿, 컴퓨터 어디서든 항상 최신 상태로 이용할 수 있습니다.

### 오프라인 지원
PWA로 설치해서 사용할 수 있습니다. 인터넷 연결이 없어도 앱이 즉시 로드되고 정상적으로 작동합니다.
